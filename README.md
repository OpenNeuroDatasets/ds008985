# Stroop and Go/No-Go fMRI in healthy adults

This BIDS dataset contains MRI recordings for 106 participants included in the
Stroop and Go/No-Go analysis. It includes T1w and T2w structural images,
multi-echo BOLD recordings for Stroop, Go/No-Go and resting state, associated
field maps, and task event timing. Sessions reflect the original acquisition
sessions. Only recordings relevant to these tasks were copied from the source
dataset. Participant identifiers are pseudonymous.

The participant list in `participants.tsv` reflects the included analysis
sample. Structural and field-map images in this upload copy were defaced and
visually checked. Acquisition-time and scanner-identifying metadata were
removed. The original acquisition BIDS archive was not modified.
