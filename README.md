# Initial partial release: structural MRI and task events

This is an initial partial release for the 106 participants in the Stroop and Go/No-Go fMRI study. It contains defaced T1w and T2w structural MRI images, participant-level age and sex metadata, and Stroop and Go/No-Go task event timing files.

Functional BOLD recordings and field maps are **not included in this version**. This version therefore cannot reproduce the paper's principal fMRI analyses or brain--behaviour findings. The missing raw imaging files are intended for a later version of this same dataset. Cite the later complete snapshot for analyses requiring functional MRI.

Participant identifiers are pseudonymous. The structural images were defaced and visually checked in the source upload copy. Acquisition-time and scanner-identifying metadata were removed.
